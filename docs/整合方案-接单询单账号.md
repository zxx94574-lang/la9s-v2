## 一句话

主流程一步不动（报价 → 找货 → 销售单 · 客户确认 → 复检出库 → 签收对账 → 收款）。这次只是在最前面加一道统一的「前门」：**询单**。谁没有定价权，谁就从询单进；有定价权的（中方）和代中方接单的（仓库主管 / 热线）照旧直接建报价。

## 谁 → 从哪进 → 看到什么 → 建出什么

| 谁 | 入口 | 库存 | 价格 | 选客户 | 建出的单 |
|---|---|---|---|---|---|
| 游客（不登录） | 只有询单页 | 有货 / 少量 / 可预订 | 不看 | 留姓名 + 电话 | 询单（来源：游客） |
| 客户账号（只给大客户开；老板 / 店员） | 询单页 + 我的订单 + 我的账单 + 我的看板 | 真实可售片数 + 可预订（开关） | 只看自己的价（开关；店员默认关） | 就是他自己 | 询单（来源：客户） |
| 外跑销售 | 询单页（手机为主） | 具体片数 + 可预订 | 中方定价前不看 | 只列自己名下客户 + 新潜客 | 询单（来源：员工） |
| 仓库主管 / 热线 | 订单总览「＋ 新订单」 | 具体片数 | 本单档位价 | 全部客户 | 报价（照旧） |
| 中方 | 同上 | 全部 | 全部 + 成本 | 全部 | 报价（照旧） |

## 询单怎么走

1. 提交 → 生成编号 `IQ-年月日-序号`，页面上显示出来（游客可以把编号发给我们）。
2. 进中方待办「新询单」。中方点开：价格已按客户档位 / 促销价自动带好，可改。
3. 中方点「转成报价」：游客的先用姓名电话建潜客；询单内容带成一张报价（订单号 `CI-…`），询单和订单互相能点过去。
4. 系统通知建单的人「价格出来了」。销售在自己的询单里看到最终价。
5. 之后和现在一样，只是「确认客户 / 下推找货 / 发销售单给客户确认」这三下，**销售对自己名下的客户也能点**（现在只有热线 / 主管能点）。
6. 没成交 → 必须选原因（没货 / 价格 / 客户不回 / 其他）。

询单状态：新询单 → 已联系 → 已报价 → 已转订单（挂订单号）/ 没成交（挂原因）。每一步记谁、什么时候。询单转化率进看板和时效页。

## 不变的底线

- 价格、特价、赊账只有中方定。销售改价 = 申请。
- 客户账号永远看不到成本、别的档位价、别人的成交价。
- 审批（欠款、亏钱、新客户、超上限）原样。
- 销售只接自己名下的客户；别人的客户只看不接。

## 客户归属

- 客户挂在员工账号上（工号 = 账号，是同一个东西），但加三样：
  - 一键「移交客户」：把某人名下全部或勾选的客户转给另一个人，留移交记录。
  - 归属历史：谁在哪段时间负责。提成照旧按出库那一刻的归属人算。
  - 停用账号时强制弹移交；不移交的进「待认领客户」池。

## 权限

- 权限矩阵加三列：游客 / 客户老板 / 店员，和员工岗位同一张表，中方可调。
- 客户档案里每个客户账号两个开关：「看具体库存」「看价格」。
- 游客「少量」的线：规则参数，默认低于 50 片。

## 要 Frank 定的一件事

客户账号自己下的询单，价格是他自己的档位价（他本来就看得到）。这种询单是：
- A（建议）：仍然先进中方待办看一眼，中方点了才变成报价；
