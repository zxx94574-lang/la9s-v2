## 二、这次要新做 / 改的（已定）

1. **直接下单（熟客跳过报价）**：只给已定档客户。下推找货前自动查三道关，不过就停住转给对的人：
   - 价格：每行是档位价 / 促销价；客户嫌贵的行员工点「要议价」→ 中方议价（批的地方标红 + 原因）→ 自动放行；
   - 欠款：超上限 / 超账期 → 停住，按钮直接跳付款 / 对账，进**财务紧急待办**，财务对完账登记收款 → 自动放行（出库前再查一次）；
   - 特批：中方直接批。
   - **员工替客户下单要贴客户原话截图**（群里那条）；**客户用自己账号下单不用截图**，提交前弹确认框（N 个型号、多少片、多少钱）。
   - 议价批完后找货数量变了不用再批；加了新型号要重过价格关。
   - 新客户 / 没定档 → 照旧走报价。
2. **接单人**：= 负责给这个客户建单的人。默认只有仓库主管有「直接下单」权限，中方在权限表里可以开给其他岗位；客户档案设接单人，决定待办先推给谁。
3. **权限三层全查**：岗位（页 / 按钮，用权限表）× 数据范围（销售只看自己客户、客户只看自己、店员只看自己店）× 字段（成本 / 利润 / 底价 / 在途只给中方；单号预览、导出、分组小计、档案、提示框这些边角都要查）。
4. **客户账号（侧栏单独一块，只中方）**：A 我们卖给他的（拿货量、欠款、账号状态、能看什么、名下店铺）+ B 他店里的收银。
   - **收银**：给店员用，选货 → 价格 → 收钱 → 完结进当天流水；没有找货 / 出库 / 签收；默认「零售客人」不记名，批发客户可记名；老板看今天收了多少、卖得多的货；以后接扫码枪。
   - **他店里的库存按「来源 / 品质」分**（不按价格分）：我们出的货自动标 LA&9S、自动进他库存；别家的货他自己录、选品质标签；同型号同品质 = 一份库存，每份有他自己定的零售价。
   - 他店里的账和我们的应收 / 资金账户**完全分开**；他看不到我们的价格和成本。
5. **到货分配 + 想要**：想要有效期默认 14 天（⚙ 可调），过期不算；到货先出「还要吗」名单给热线，标 还要 / 不要了（找别人买了）/ 联系不上，只有「还要」进分配；中方填每人分多少 → 生成热线电话名单。备货申请分开看：实际卖出趋势、下单时没供够的缺口、想要 × 客户兑现率；「不要了（找别人买了）」单独统计（缺货丢单）。
6. **批准规则**：员工做的、涉及钱和货的（改价、库存变动、动账）都要中方批；中方自己做的不卡，只通知另一位中方（Frank 和汪波权限一样）。批准一个入口：跳到那张单，要批的地方标红，写清谁要求、原因、批了会变成什么（改前 → 改后、毛利、欠款），驳回要写一句。中方入账每笔通知 + 每天汇总。
7. **冻结的货不算可售**：可售 = 实存 − 预占 − 冻结；选货、报价、客户端都不能算成可卖。冻结原因加「待评估（软件 / 版本）」。
8. **478 / 479 / 480 指令**：制单指令；「我下达的指令」排第一（指令 / 定期任务两个页签）；完成凭证可选系统里的记录（订单、收款单、出库单、拜访、热线、退货），挂在单 / 客户上的指令自动挂上员工做的记录，员工点完成前能看能换；期限显示「还剩 / 超时多久」色块 + 下面小灰字时间（红 = 超时、黄 = 不到 2 小时、灰 = 够）；给谁按部门 / 主管分组带搜索可拖顺序；类型 ⚙ 加快捷类型（≥4 个自动下拉）；客户从档案选或新建潜客。
