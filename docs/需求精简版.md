## 1. 目标与边界

- LA&9S 在科特迪瓦做手机配件（屏幕、电池、电池盖等）批发零售 + 本地备货 + FOB。要一套自有系统，把「WhatsApp 群接单 → 手工录飞书 → 事后补录金蝶」这条重复劳动砍掉：**询单 → 找货 → 出库 → 对账收款 → 退货**全流程线上化。
- 十年寿命设计；先做科特，以后覆盖西非法语区；最终开放给大客户老板和他们的门店使用（客户的数据和价格要和我们**完全分开**，我们能看后台）。
- **金蝶是底线**：所有单据最终进金蝶、账要和金蝶对上；但工作流不拴死在金蝶上（金蝶太复杂、不合本地习惯）。金蝶、飞书只读，写入必须逐次授权。
- 只做科特一个国家、一套价目；客户档案保留国家字段（有 BF / TG 客户）。
- 网址统一 **la9s.com**（客户、员工、中方都用这一个）。

## 2. 角色与权限

- 岗位：中方（Frank 所有者；汪波、王振宇同权限）、销售主管（罗兰）、销售、热线、仓库主管、仓管（找货 / 复检）、财务、中国支持（国内采购）、客户老板、门店店员、游客。
- **价格 / 特价 / 赊账只能中方定**（死命令）。员工能看客户本单的档位价，看不到成本、到岸价、毛利、定价规则；客户看不到我们的底价和成交价。
- 一人一账号不共用，一个账号可挂多个岗位；**登录 = 工号 + 密码**，工号 S + 三位数（Frank 编，离职不回收）。
- 汪波 / 王振宇动底层设置一律二次确认 + 进变更记录。

- 离职：停账号，名下客户进「待认领」池，激励按出库当时的归属人算。

## 3. 订单主链（界面 6 步，底层状态不变）

**报价·确认 → 找货·初检 → 销售订单·客户确认 → 复检打包·发货文件·出库 → 签收·对账 → 收款**；退货按原单。

- 下推单向，一个业务号挂所有单据可横向回溯；可撤回到上一步。订单号 `CI-年月日-两位序号`，报价 -Q / 找货 -P / 销售 -O / 出库 -S1…
- **报价**：先选客户（含潜客、可当场新建），**先种类后型号**落到唯一编码，型号只写型号（如 BG6M），屏幕 / 电池盖放「种类」；输通用型号也能带出；需求数量默认 0，0 不让保存（红框）；价格按「物料 × 客户档位」自动带出；有编码却 0 价 / 客户没档位不让建；客户档位没定 → 报价是草稿，员工申请定级、中方定档。草稿：选了客户 + ≥5 行才存进系统，7 天没动删。
- **报价·确认**：谁建报价谁确认（主管兼热线）；报价 5 分钟没点开进紧急；「今天要」顺手下推找货，「明天要」设日期进待办，到日子前移。报价不占库存。
- **找货·初检**：下推时预占；必选找货人、现场拍照（调相机）；实际供货在原表加一列；只集中放一堆不打包。复核人 ≠ 找货人（中方除外）。
- **销售订单**：显示需求数量 + 实际供货 + 本次未供；中方改价特殊标记、下推前二次确认；批量「获取价格」先选中行、不覆盖手改价；员工改价 = 申请价走中方审批（批 / 驳都写备注）；偏离档位价超 10%（可调）标「异价单」；改动先进「本次改动」清单再提交，没提交 / 待批不能复制销售单。
- **客户确认**：先把销售单图片发客户群，再确认；确认凭证必传；约定以后发货 → 记「放在哪 + 照片」。出库前临时加货走原单追加，不重走流程。可拆单（一部分以后发）。
- **复检打包 + 出库**：仓库主管复检；出库必填 日期时间、方式（Yango 摩托 / 小汽车 / 货车、客户自取、员工送货）、电话、凭证截图；只发一部分必填原因；分批出库每批独立；发货失败可撤销。运费：默认客户付；我们出的自动记「本地物流费」支出（Wave-XOF），不进客户账。
- **发货文件**：BL ×2（G&S 抬头，严格照 Frank 11-07 样本，型号只写型号、不出中文、Type 用 LCD / OLED 代号、数量真实、无价格）；海关 QUITTANCE 单独按钮；大单建议打印。
- **签收（硬规则，11-14）**：**签收 = 跟客户确认过数量无误**。没确认数量不能填签收、不能填对账；签收必须二选一「数量无误 / 有差异当场登记」。差异（少 / 多 / 发错 / 破损）由中方处理（冲减 / 补发 / 不认），默认责任 = 复检人；处理前不能对账，处理后对账单自动刷新。
- **对账**：签收后生成客户最新 Balance（所见即所得，复制图片 / 文字 / 打印），发客户群，客户认账截图必传。
- **全程凭证**：除报价确认外，每一步照片 / 截图必传；同一张图用在多处自动提示（不审批）。

## 4. 价格与客户

- 客户四档：**S**（大客户，拓市场不求多赚）、**Wholesale shop**、**Retail shop**、**Repair shop**，价格逐级递增、档间拉开。档位只中方定；员工建的客户默认 Repair 未确认；拿货量和档位不符进中方待办（量级 Repair 0–100、Retail 100–500、Wholesale 500–10000、S 10000+ 片）。
- 到岸成本 = 采购价 CNY ÷ 该批付款汇率 + 该批每件物流费，**进到下一个 100 XOF**；加价按 MI 的 S / A / B / C FEE。三个价：挂牌价（在库最高批次成本 + 加价）、可让价下限（最低批次成本 + 最低加价，低于要中方写原因）、先进先出毛利；老批次卖完提示可降价（人点才降），新批次更贵立即上调；限时促销价到期自动恢复。
- 外币报价 = XOF 档位价 ÷ 手填汇率，两位小数。
- **上次成交价**：报价 / 销售订单时和该客户该型号上次成交价不同要提示；「历史价格」就地看（只看本单型号 / 该客户全部成交，后者用订单总览那张表）；弹窗里「应用历史订单价格」，员工应用要中方批。S 档推荐用历史价但**不强制**，不自动报中方。
- **整单优惠**（大客户近万片每片减 50 这种）：按片减 / 整单减固定金额，中方批，单价不动，金蝶按行分摊；上次成交价取优惠前单价。抹零另算（小额、只中方）。
- 已出库后调价走「价格调整单」（只中方，进客户账，不录金蝶）。
- 客户编码统一 CI000x（和金蝶、飞书一致）；潜客无编码，转正式给下一个号。客户有归属销售员、供货方式（本地备货 / FOB）、跟进状态等，选项和自定义列中方维护。

## 5. 库存与仓库

- 库存三列：实存 / 预占 / 可售。
- 本地出货只用 **LA 仓、9S 仓**；待检、报废、回收仓永不自动匹配；FOB 仓可手选不自动匹配；同编码多仓不自动拿别的仓补差，要手动另加一行。
- 仓库对照金蝶固定（LA / 9S / LA FOB / Pending / Defective 按货权两个 / 回收）。
- 编码只在金蝶（国内采购）建；编码三层：金蝶料号 → 归一编码 → 系统物料，通用性不同的不归一，归一由 Frank 逐组定；出库记实际料号。
- 可冻结库存（凭证必传，冻结期间不能出库）。
- **未满足需求**（核心差异化，备货依据）：客户要了但没编码的型号、要 100 给 60 的缺口，分开记录；补录先种类后型号、自动大写、相似提示。

## 6. 收款、资金与总账

- 客户总账**只在出库后**增加；正数欠款、负数预付。冲账默认冲最老的单，也可指定 / 手动分配多单；有未处理差异的单自动冲时跳过；多冲的自动退回预付。跨币种锁当时汇率，原币和折算额都保留。
- **收款渠道**：现金（没手续费）、我们的 Wave、Orange、**Roland 公户（Wave / 银行）**；公司没有别的银行账户。
- **手续费规则（11-14 / 11-15）**：客户账**永远按货款冲**；每笔收款一个开关「我们承担手续费」，默认否；选是 → 实际到账（默认 99%）与货款的差额自动记 **Wave-XOF「办公费」**，再跳转让中方确认。客户自己出手续费（转 10,100 到 10,000）就不记支出。
- **Roland 公户**：客户付到这里当天登记、客户账冲全额，但钱在 Roland 手里不算到我们手；Roland 分次交回、交回差额 = 手续费；要能按笔追溯和出总数，压款超期进中方待办。
- 员工代收的钱当天交，超 1 天不论金额都紧急。销售员名下任何客户有前一天以前出库没付清的 → 名下所有客户不能出库（当天不追；可申诉，中方放行）。客户可设「有欠款不出货」。
- 大额审核：触发条件可设（≥100 万 XOF、低于可让下限、新客户、超欠款上限、超账期），**只拦出库不拦找货**；客户可设免审额度。
- 资金账户：Cash-XOF / Wave-XOF / Cash-RMB / Cash-USD / Roland Wave / Roland 银行（Orange 待加）；对账盘点、互转在途、月结锁账、核销坏账、退款给客户。个人收款号有滚动上限，快满提醒提现。

## 7. 退货

- 必须关联原单原行，填数量和原因，**审批后**生效；收货时间 + 实物照片必传；先进待检仓，好货回原仓、坏货进报废仓；退货后和客户对账（凭证必传）才算完。
- 不做换货（退了另开新单）；欠款客户也能退。24 小时损坏反馈规则未定。

## 8. FOB 与采购

- **FOB** 是独立项目、一客一单：申请 → 采购 → 入库 → FOB 销售 → 出库收款；常规 30% 订金 / 70% 尾款，放货人工决定；科特仓库控货、多哥等国物流控货。FOB 和本地同编码不同仓、库存分开；本地和 FOB 不在同一张采购单上，但可同一批发货。
- **采购**：国内先在金蝶建采购单，系统沿用金蝶单号；箱单 Excel 导入（入仓号 CG… / LKY… / TG… 是箱单 ↔ 金蝶 ↔ 到货的钥匙）；按箱到货、照片必传；差额中方关单（结果 + 凭证）；国内同事只能导入 / 更新物流，看不到价格和客户。
- 备货：自动预警 → 人工审批的备货申请；用月销量 + 未满足需求算；断过货的型号销量要估。

## 9. 客户开发与回访

- 销售拜访表：日期、员工（按账号）、客户全名 / 电话 / 位置 / 照片 / 从哪买 / 卖什么 / 海运空运等；拜访自动生成潜客。
- 热线：每天按名单打电话（已成交 / 未成交 / 回收员工导入 / 偶然得到的号码），记结果，可转潜客；热线本质是通知客户（客户不看消息就打电话）。
- 客户 1 天不回 = 紧急（只有紧急 / 不急两档）；每张单都要有清楚的结局记录（含客户不要了）。

## 10. HR、打卡与工资

- 员工档案：工号、全称、简称、部门、职位、入职日期、负责城市、电话、邮箱、住址、身份证照片（只中方看、查看留记录）；离职档全保留。Frank 在真实版里手改的员工资料是唯一真相。
- 上班 9:00–17:30，午休 1 小时，周六到 12:00；工资周六按全天。打卡带定位：仓库固定点（5.388056, -4.002583）+ 100 米；市场不预设，200 米内自动聚点、新地点中方命名。迟到 / 缺勤自动扣，员工可申诉。请假员工自填、不审批，进出勤。
- 工资：基本工资 = 月薪 ÷ 当月周一至周六工作日数 × 实到天数；补贴 / 个人奖金 / 团队奖金三栏，自动值可改，偏差超 ±10% 标出；仓库提成 5 XOF / 片正确出货，出错（不论多少）整单提成取消、记复检人，工资单写清哪单为什么；CNPS 公司交、不进实发（待最终确认）；草稿 → 中方确认发放后锁定，撤回要原因。工资可见：中方三人 + 罗兰。导出 Excel 照 8 月表样式。
- 中方指令：只中方下达，员工收到（超 5 分钟写原因）→ 完成填结果（文字 / 照片）→ 中方确认才关；紧急每小时、普通每天 9:30 提醒；超时升级 Frank；可设定期任务。不做延期申请。
- 时效与准确率：按步骤、只算上班时间，看速度和准确率，**只显示不考核**。
- 各部门 SOP 放进系统，和操作步骤联动。

## 11. 金蝶对齐

- 金蝶是云星空，有 WebAPI；部署后让国内管理员建第三方授权自动录单，没授权前用引入模板 Excel 退路。现在人工录：签收 + 对账完才补录，保存 → 提交 → 审核三步分开（审核归主管或中方）。
- 进金蝶的：销售出库、采购入库、退货、收款（定期批量）、其他出入库 / 调拨、FOB 订金尾款；价格调整单不单独录。每单记金蝶状态，金蝶单号抄回系统（不强求同号）。
- 库存差异：粘金蝶即时库存导出 → 逐编码比对，差异只 Frank 看。应收：先和飞书对齐，金蝶差额进期初差异表，最终以金蝶为准。
- 对齐口径（待 Frank 认可）：编码、数量、仓库、单价金额、币种、客户编码、采购单号必须一致；销售单号、机型显示名、通用性、流程只存对照。

## 12. 通知与渠道

- **不做**电话机器人、WhatsApp Business 接口、「回复 OK」机器人。替代：网页加主屏幕推送；未「收到」的指令强制弹窗；超时升级 Frank 亲自打电话；系统生成写好的 WhatsApp 消息一键跳转手动发（提醒、Balance）。
- 待办分紧急 / 进行中 / 不急三段；审批中、等定档、被冻结、销售单发出超 1 天、报价 5 分钟没点开、卡单一律进紧急；钱的问题（付款申诉、代收超期、账对不上）放最顶。**同类事超过 5 条改成数字块，点进去看清单。**
- 确认后又改数量 / 改价 / 撤回 / 拆单等不走正常流程的改动进「变更通知」。

## 13. 单据

- 给客户的单据：报价单、销售单、Balance、发货清单、大额发票清单（等 PDF 模板）；**不出现地址、电话等联系方式**（BL 例外，保留 G&S 抬头和客户电话）；只用 LA&9S logo，单据标题不加「LA&9S」前缀。发货发票 = BL（G&S）；订单发票 = LA&9S。
- 报价单 / 销售单 / Balance 能**复制成图片**发 WhatsApp；打印用浏览器原生打印，横竖线同样粗细。
- 语言一个开关管界面和单据（中 / 英 / 法）；**法语上线前必须完成**；金额千分位逗号，XOF 无小数、CNY / USD 两位。

## 14. 界面规则（Frank 多次强调）

- 品牌蓝 `#0447b0` + 黑字 + 灰（空 / 未选）三色；状态只用红 / 黄 / 绿浅底小字块，档位固定色 S 黄、Wholesale 红、Retail 蓝、Repair 绿。实心蓝按钮只给保存 / 下推这类主动作。
- 核对标记三色：红 = 肯定有问题（会亏）、黄 = 要留意（手改、低于档位）、绿 = 没问题；员工看不到价格类标记。
- **表格像 Excel / 飞书**：点一下选中、再点 / 回车 / 打字进编辑；回车下移、Tab 右移；拖选区域、复制粘贴只填选中区；改一格存一格；⌘Z / ⌘⇧Z；列可拖、可隐藏、拖宽、相邻列让位有动画；表头加粗、全部左对齐；排序空白排最后；飞书式筛选 + 全表搜索 + 筛选方案；滚轮上下滚页、Shift + 滚轮左右滚表。格子里只放最简信息（型号只写型号），想看点开档案；格内不放按钮（只改这一格的小图标除外），行操作放表格上方。
